Privacy Policy

BeSchool C++ Final Exam Platform

Last updated: November 2, 2026

1. Information We Collect

When students sign in using Google, the platform receives basic account information such as their name, email address, and Google account identifier.

The platform also records exam-related information, including exam start and submission times, attempt status, answers, and scores.

2. How We Use Information

Information is used to authenticate students, manage exam access, enforce the one-attempt policy, save exam progress, evaluate answers, and calculate final scores.

3. Data Storage

Student and exam records are stored using Google Sheets through a restricted service account. Access is limited to authorized platform administrators.

4. Code Execution

When a student runs a C++ solution, the submitted source code and required input may be sent to the configured code execution service for compilation and testing.

5. Third-Party Services

The platform uses Google services for authentication and data storage, and a code execution service for programming questions. These services process information according to their own privacy policies and terms.

6. Data Security and Retention

Reasonable measures are used to protect stored information. Exam records may be retained for grading, academic review, and administrative purposes. No online system can guarantee absolute security.

7. Student Rights and Contact

For questions about personal information, data correction, or deletion requests, contact the platform administrator using the official contact details provided by your institution.

8. Changes to This Policy

This policy may be updated when platform features or data handling practices change.
